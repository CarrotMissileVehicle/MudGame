## 一、总体继承体系

所有游戏对象（作物/鱼/肥料）继承自统一基类 `Object`：

```
Object（根基类，虚析构）
  │
  ├── Crop（抽象：纯虚 grow/harvest）
  │     ├── Cabbage        //小白菜
  │     ├── Carrot         //胡萝卜
  │     ├── Tomato         //西红柿
  │     ├── Pumpkin        //南瓜（头文件名拼写错误 Punpkin.h）
  │     └── Lingzhi        //灵芝
  │
  ├── Fish（虚方法 specialPurpose 带默认空实现）
  │     ├── Crucian        //小鲫鱼（override 了 specialPurpose，空实现）
  │     ├── GrassCarp      //草鱼
  │     ├── Perch          //鲈鱼
  │     ├── RainbowTrout   //彩虹鳟鱼
  │     └── KingCrab       //帝王蟹
  │
  └── Fertilizer（构造/析构为 protected，不可直接实例化）
        ├── NormalFertilizer     //普通肥料：周期减半（speedUp=2）
        └── AdvancedFertilizer   //高级肥料：周期减为 1/3（speedUp=3）
```

独立的领域模型与控制器（不在 Object 继承树内）：
- `Farm` / `FarmLand`（农田领域模型，组合关系）
- `FarmingController`（种田控制器，薄委托层）
- `FishingController`（钓鱼控制器，薄委托层）

## 二、Object 根基类（`controller/Objects/`）

- 构造函数：`Object(int sellingPrice = 0, int buyingPrice = 0)`，带默认值，兼作默认与带参构造。
- **虚析构** `virtual ~Object()`：多态基类，确保通过基类指针删除时正确释放。
- 成员（protected）：`int sellingPrice; int buyingPrice;`
- 方法：`getSellingPrice()`、`getBuyingPrice()`（非虚 getter）。
- 设计要点：成员用 `protected` 供派生类直接访问；`virtual` 析构是唯一虚成员。

## 三、Crop 子系统（`controller/Crop/`）

### 中间抽象类 `Crop`（继承 Object）

- 构造函数：`Crop(int growthCycle, int yield, int farmExp, int unlockLevel, int sellingPrice, int buyingPrice)`
- 成员（private）：
  - `int growthCycle`  //生长周期
  - `int yield`        //收获数量
  - `int farmExp`      //农业经验
  - `int unlockLevel`  //解锁等级
  - `bool isUnLocked = false`  //是否解锁，构造时 `unlockLevel <= 1` 自动解锁
- 方法：getter（`getGrowthCycle`/`getYield`/`getFarmExp`/`getUnlockLevel`/`isUnlocked`）、`unlock()`。
- **纯虚方法**：`virtual void grow() = 0;`、`virtual void harvest() = 0;`

### 具体作物（叶子类）

每个作物 = **无参构造函数 + 把全部数值硬编码传给 Crop 基类**，不新增成员/方法，只 override `grow()`/`harvest()`（当前均为空实现 stub）。

| 类 | growthCycle | yield | farmExp | unlockLevel | sell | buy |
|----|------------|-------|---------|-------------|------|-----|
| Cabbage 小白菜 | 2 | 2 | 12 | 1 | 8 | 5 |
| Carrot 胡萝卜 | 3 | 2 | 8 | 1 | 12 | 8 |
| Tomato 西红柿 | 4 | 3 | 8 | 2 | 10 | 15 |
| Pumpkin 南瓜 | 5 | 1 | 15 | 3 | 40 | 25 |
| Lingzhi 灵芝 | 6 | 1 | 50 | 10 | 40 | 60 |

## 四、Fish 子系统（`controller/Fish/`）

### 中间类 `Fish`（继承 Object）

- 构造函数：`Fish(float probability, int fishExp, int sellingPrice, int buyingPrice)`
- 成员（private）：`float probability`、`int fishExp`
- 方法：`getProbability()`、`getFishExp()`、**`virtual void specialPurpose() {}`**（虚带默认空实现，可选 override，非纯虚）。
- 与 Crop 不同：Fish **不是抽象类**。

### 具体鱼类（叶子类）

同样采用「无参构造硬编码数据」模式。**所有鱼的 buy 价都是 0**（鱼不可购买）。稀有度越低概率越低、售价和经验越高。仅 `Crucian` override 了 `specialPurpose()`（当前为空 stub）。

| 类 | probability | fishExp | sell | buy | override specialPurpose |
|----|------------|---------|------|-----|------------------------|
| Crucian 小鲫鱼 | 0.40 | 5 | 10 | 0 | 是（空实现） |
| GrassCarp 草鱼 | 0.30 | 8 | 15 | 0 | 否 |
| Perch 鲈鱼 | 0.20 | 12 | 25 | 0 | 否 |
| RainbowTrout 彩虹鳟鱼 | 0.08 | 20 | 50 | 0 | 否 |
| KingCrab 帝王蟹 | 0.02 | 40 | 200 | 0 | 否 |

## 五、Fertilizer 子系统（`controller/Fertilizer/`）

### 中间类 `Fertilizer`（继承 Object）

- 构造函数：`Fertilizer(int speedUp, int sellingPrice, int buyingPrice)` — **`protected`**。
- 析构：`~Fertilizer()` — **`protected`**。
- 成员（private）：`int speedUp`（剩余生长周期的加速除数：2 减半，3 减为 1/3）。
- 方法：`getSpeedUp()`。
- 设计要点：**无纯虚方法，但构造/析构为 protected**，以此禁止直接实例化（与 Crop 的纯虚、Fish 的公共构造三种模式不同）。

### 具体肥料

| 类 | speedUp | sell | buy |
|----|---------|------|-----|
| NormalFertilizer 普通肥料 | 2 | 5 | 10 |
| AdvancedFertilizer 高级肥料 | 3 | 15 | 30 |

## 六、Farm 子系统（`controller/Farm/`，组合式领域模型）

### `FarmLand`（地块，独立类）

- 构造函数：`explicit FarmLand(Crop* crop = nullptr)` — `explicit` 防隐式转换，默认无作物。
- 成员（private）：
  - `bool occupied = false`  //是否占用
  - `bool watered = false`   //是否浇水
  - `Crop* crop = nullptr`   //所种作物（裸指针）
  - `int growthStage = 0`    //当前生长阶段
- 方法：
  - `sow(Crop*)` — 已占用或 seed 为空时返回 false
  - `water()` — 未占用时返回 false
  - `fertilize(int speedUp)` — `growthStage += growthStage / speedUp`
  - `harvest()` — 满生长周期时返回 yield 并重置状态，否则 0
  - `tickGrow(bool growFullSpeed)` — 阶段 +1（满速 +2），并置 `watered=true`

### `Farm`（农田集合，独立类）

- 构造函数：`explicit Farm(const std::vector<FarmLand>& farmlands)`
- 成员（private）：`std::vector<FarmLand> farmlands`（按值持有地块）
- 方法：`size()`、`getFarmland(index)`（含 const 重载，用 `.at()` 越界检查）、`add()`、`tickAll(bool)`。
- 设计要点：组合式领域模型（非继承），`Farm` 按值持有 `vector<FarmLand>`。

## 七、FarmingController（`controller/Farming/`，薄委托控制器）

- 构造函数：`explicit FarmingController(Farm* farm)` — 注**非拥有**裸指针。
- 成员：`Farm* farm`（非拥有指针）
- 方法：`sow(index, seed)`、`water(index)`、`waterAll()`、`fertilize(index, fertilizer)`、`harvest(index)`、`tick(isDaytime)`、`farmSize()`。
- 设计模式（MVC 薄委托）：
  1. 构造函数注入非拥有指针；
  2. 每个方法开头做 **null 检查**（`if (farm == nullptr)`）；
  3. 业务逻辑全部委托给 Model（`Farm`/`FarmLand`）；
  4. 仅保留协调逻辑（如 `waterAll`、`tick`）；自身不含领域状态。

## 八、FishingController（`controller/Fishing/`，薄委托控制器）

- 构造函数：`explicit FishingController(const std::vector<Fish*>& fishPool)` — 浅拷贝指针 vector。
- 成员：`std::vector<Fish*> fishPool`（拷贝指针，非深拷贝）
- 方法：`rollFish()`（按 `getProbability()` 加权随机）、`poolSize()`。
- `rollFish()` 算法：累加总概率 → `rand()/RAND_MAX` 取 [0,total) 随机数 → 按累积概率选中 → 兜底返回 `fishPool.back()`。
- 说明：与 FarmingController 不同，此控制器**拷贝持有鱼池指针**，且 `rollFish()` 内含实际算法逻辑（严格 MVC 视角下，该逻辑更应放 Model）。

## 九、跨子系统的通用模板模式

| 模式 | 说明 |
|------|------|
| **数据块叶子类** | 每个具体叶子类（作物/鱼/肥料子类）不新增成员与方法，仅通过无参构造函数硬编码数值游戏数据 |
| **构造初始化链** | 逐级用成员初始化列表向上传递数据：叶子类 → 中间类 → Object |
| **基类虚析构** | `Object` 有 `virtual ~Object`，中间类用 `override` 标记析构 |
| **const 正确性** | 所有 getter / 只读方法标记 `const` |
| **explicit 构造函数** | `Farm`/`FarmLand`/`FarmingController`/`FishingController` 用 `explicit` 防隐式转换 |
| **裸指针（无智能指针）** | 全项目未使用 `unique_ptr`/`shared_ptr`，所有权语义隐含（`FarmLand` 拥有 `Crop*`，控制器不拥有） |
| **空析构函数** | 所有析构函数体均为 `{}`，无资源清理（依赖裸指针，无 RAII） |
| **null 防御** | 两个控制器在每个方法入口都做 `if (ptr == nullptr)` 检查 |
| **override 关键字** | 派生类对虚方法与析构一致使用 `override` |

## 十、已知问题与待办（源码现状）

1. **空实现 stub**：所有作物子类的 `grow()`/`harvest()` 为空；`Crucian::specialPurpose()` 为空。均标了 `override` 但无逻辑。
2. **头文件名拼写错误**：`Punpkin.h`（缺 'm'），但类名/守卫名正确为 `Pumpkin`。
3. **大小写不一致**：`farmland.h`/`farm.h`（小写）与 `Farm.cpp`/`FarmLand.cpp`（大驼峰）混用。
4. **所有权模糊**：`FarmLand` 持有裸 `Crop*` 无明确所有权契约，调用方 `sow()` 后若自行 delete 该指针会造成悬垂；`FishingController` 拷贝指针 vector 同理。
5. **`Fertilizer` 用 protected 构造/析构** 强制不可实例化，与 Crop（纯虚）、Fish（公共构造）三种模式，需注意统一风格。
