# 悠闲农场 MUD 游戏项目书

## 项目概述

**项目名称：** 悠闲农场（Idle Farm）

**项目类型：** 文字/休闲 MUD 游戏

**核心玩法：** 钓鱼、种菜、采矿、集市交易

**目标用户：** 喜欢轻松节奏、经营模拟的休闲玩家

**技术栈：** C++

**架构模式：** MVC（Model-View-Controller）

**初始资金：** 50 金币

**游戏时间倍速：** 现实 1 秒 = 游戏 60 秒（1 分钟）

---

## 玩家属性

| 属性 | 说明 |
|------|------|
| 饱食度 | 上限 100，自然衰减，吃食物恢复；低于 30 时行动速度减半，归零时无法行动 |
| 金币 | 货币，用于购买种子/工具/材料/修复 |
| 农业经验值 | 收获作物获得，决定农业等级 |
| 钓鱼经验值 | 钓鱼获得，决定钓鱼等级 |
| 采矿经验值 | 采矿获得，决定采矿等级（≤农业等级） |

## 时间系统

### 昼夜循环

- 游戏时间每 60 秒 = 现实 1 秒
- 一天 = 游戏 24 小时 = 现实 24 分钟
- 白天：06:00 - 18:00（正常速度）
- 黑夜：18:00 - 06:00（采矿和种田速度减半）

| 时间点 | 通知内容 |
|--------|---------|

| 12:00 | 中午了 |
| 18:00 | 天黑了，你感到疲倦，挖矿和种田速度减半 |
| 00:00 | 深夜了 |

### 突发事件触发

突发事件固定在游戏内早上 8:00 触发。

## 核心系统

### 1. 饱食度系统

- 上限：100
- 每天自然衰减：20（游戏时间 24 分钟）
- 低于 30：采矿和种田速度减半
- 归零：无法行动，必须进食
- 进食恢复：普通食物 +30，料理 +60，高级料理 +100

### 2. 种菜系统

#### 作物分类

| 类型 | 说明 | 特点 |
|------|------|------|
| 经济作物 | 售价高，经验低 | 适合攒钱 |
| 经验作物 | 经验高，售价低 | 适合升级 |
| 均衡作物 | 售价和经验适中 | 稳定发展 |

#### 作物一览（5 种）

| 作物 | 类型 | 种子价格 | 生长周期 | 收获数量 | 售价 | 农业经验 | 解锁条件 |
|------|------|---------|---------|---------|------|---------|---------|
| 小白菜 | 经验 | 5 | 2天 | 2 | 8/个 | +12 | 初始 |
| 胡萝卜 | 经济 | 8 | 3天 | 2 | 12/个 | +8 | 初始 |
| 番茄 | 经济 | 15 | 4天 | 3 | 10/个 | +8 | 农业等级2 |
| 南瓜 | 经济 | 25 | 5天 | 1 | 40/个 | +15 | 农业等级3 |
| 灵芝草 | 经验 | 60 | 6天 | 1 | 40/个 | +50 | 农业等级10 |

#### 种菜流程

```
选择空地 → 选择种子 → 播种 → 浇水（消耗饱食度 5/块）→ 等待生长 → 收获
```

- 一键浇水：对所有已种植地块一次性浇水，消耗饱食度 = 地块数 × 5
- 施肥：消耗肥料，使作物剩余成熟时间改变，产量增加
- 天气影响：雨天自动浇水，干旱减产 30%
- 农田升级：可开垦更多地块（最多 3×4=12 块）

#### 肥料

| 肥料 | 价格 | 效果 |
|------|------|------|
| 普通肥料 | 10 金币 | 作物剩余生长周期减半 |
| 高级肥料 | 30 金币 | 作物剩余生长周期减为 1/3 |

#### 鱼类一览（5 种）

|------|---------|---------|------|---------|---------|
| 小鲫鱼 | 海岸 | 40% | 10  | +5 | 恢复饱食度 +15 |
| 草鱼 | 海岸 | 30% | 15 | +8 | — |
| 鲈鱼 | 海岸 | 20% | 25 | +12 | — |
| 彩虹鳟鱼 | 海岸 | 8% | 50 | +20 | 稀有料理食材 |
| 帝王蟹 | 海岸 | 2% | 200 | +40 | 高价收购品 |

#### 钓鱼流程

```
前往海岸 → 开始钓鱼（挂机）→ 随机时间产出鱼 → 获得鱼/空竿
```

- 技能等级：钓鱼等级越高，稀有鱼概率提升

| 赤耀金 | 深层及以上 | 60 | +20 | 贵重品/升级材料 |

#### 各矿区矿石出现概率

| 矿区 | 黯铁矿 | 星纹银 | 赤耀金 | 雷鸣晶 | 世界之核 |
|------|--------|--------|--------|--------|---------|
| 浅层 | 70% | 25% | 5% | — | — |
| 中层 | 40% | 40% | 15% | 5% | — |
| 深层 | 15% | 35% | 35% | 13% | 2% |
| 水晶层 | 5% | 15% | 30% | 40% | 10% |

#### 采矿流程（挂机机制）

```
前往矿洞 → 选择矿区 → 开始采矿（自动挂机产出）→ 随时间获得矿石 → 停止采矿
```

- 挂机期间每隔固定时间自动产出一块矿石
- 玩家可随时停止采矿，矿石已产出的自动存入背包
- 矿镐升级：提升稀有矿石概率，加快产出速度
- 照明需求：深层矿区需要火把/灯笼（可在小镇购买）
- 采矿等级经验节点沿用农业等级

## 集市系统

集市是游戏的核心经济枢纽，包含日历、商店交易与供需波动三大模块。

### 集市日历

集市根据游戏内星期与日期自动切换模式：

| 模式 | 触发条件 | 效果 |
|------|---------|------|
| 普通集 | 每日 | 价格正常 |
| 繁华集 | 每周三 | 所有物品售价 +20% |
| 节日集 | 每月 1 日 | 稀有商品上架，限定事件触发 |

日历随游戏天数自动推进，由 `Market::onNewDay(week, day)` 更新。

### 商店系统

集市包含 5 家商店，每家商店独立管理自己的商品列表：

| 商店 | ID | 主营 | 特色 |
|------|-----|------|------|
| 种子铺 | `shop_seed` | 种子、肥料 | 按季节上新 |
| 渔具店 | `shop_fishing` | 鱼竿、鱼饵 | 收购鱼类 |
| 矿具店 | `shop_mining` | 矿镐、火把 | 收购矿石 |
| 杂货铺 | `shop_general` | 食物 | 恢复饱食度 |
| 铁匠铺 | `shop_smith` | 工具升级、工具修复 | 消耗矿石升级，消耗金币修复 |

每家商店的商品由 `ShopItem` 条目管理，包含物品指针、基础价格与当日实际价格。

### 交易机制

#### 买入

- 玩家选择商店 → 选择商品 → 输入数量 → 扣除金币 → 物品加入背包
- 购买价 = 商品基础价 × 当日供需浮动系数
- 金币不足时无法购买

#### 卖出

- 玩家选择背包物品 → 输入数量 → 获得金币
- 售价 = 物品基础售价 × 当日供需浮动系数
- 繁华集额外 +20%

#### 供需波动

- 每天自动触发，随机选择 2-3 种在售商品
- 浮动范围：基础价格 × (0.7 ~ 1.3)，即 ±30%
- 波动结果保存在 `fluctuations` 映射中，当天有效

### 核心类结构

```
Market
├── dayOfWeek / dayOfMonth      // 日历状态
├── shops: vector<Shop>         // 商店列表
├── fluctuations: map<Object*, float>  // 当日价格浮动
│
├── onNewDay(week, day)         // 推进日历 + 刷新浮动
├── registerShop(shop)          // 注册商店
├── findShop(id)                // 按 ID 查找商店
├── findShopByItem(item)        // 按物品反查所属商店
│
├── updateFluctuations()        // 生成当日供需波动
├── getFluctuation(item)        // 查询某物品浮动系数
│
├── getSellPrice(item)          // 计算售价（含浮动 + 繁华集加成）
├── getBuyPrice(shopId, item)   // 计算购买价（含浮动）
│
├── buy(shopId, item, count, gold)   // 购买，扣款
└── sell(item, count, gold)          // 出售，加款

Shop
├── id / name                   // 商店标识与名称
├── items: vector<ShopItem>     // 商品列表
├── addItem(item)               // 添加商品
├── getItem(index)              // 获取商品
├── getBuyPrice(item)           // 查询某物品当日购买价
└── itemCount()                 // 商品数量

ShopItem
├── item: Object*               // 物品指针
└── getItem()                   // 价格一律取自物品自身，不再另设
```

### 工具修复系统

- 所有工具有耐久度，使用后损耗
- 耐久度 ≤ 1 时工具不可使用
- 在铁匠铺花费金币修复
- 可用矿石材料修复，费用减半

## 任务系统

### 主线任务

1. **继承农庄** → 获得初始田地和小屋（新手引导）
2. **第一桶金** → 在集市卖出 100 金币
3. **田园扩张** → 农田升级到 3 级
4. **钓鱼高手** → 钓到稀有彩虹鳟鱼
5. **矿坑探秘** → 采矿等级达到 3 级
6. **集市大亨** → 累计交易额 5000 金币

### 每日任务（随机 3 个/天）

- 种植 X 根胡萝卜
- 钓到 X 条鱼
- 挖到 X 块矿石
- 在集市卖出 X 件物品
- 获得 X 金币收入

### 订单系统

- NPC 随机发布订单（如：需要 5 个番茄）
- 完成订单获得金币+经验值
- 稀有订单需要特殊物品，奖励翻倍

## 技术架构

采用 MVC 架构：

```
src/
├── main.cpp
│
├── model/                          # Model - 数据与逻辑
│   ├── player.h                    # 玩家数据（饱食度/金币/三套经验）
│   ├── inventory.h                 # 背包系统（无限容量）
│   ├── farm.h                      # 农田数据（地块状态）
│   ├── time_system.h               # 时间系统（昼夜/60倍速）
│   ├── weather.h                   # 天气系统
│   └── event.h                     # 随机事件数据
│
├── controller/                     # Controller - 游戏逻辑控制
│   ├── game_controller.h           # 游戏主控制器
│   ├── state_machine.h             # 玩家状态机（行走/种田/钓鱼/采矿）
│   ├── farming_controller.h        # 种菜逻辑
│   ├── fishing_controller.h        # 钓鱼逻辑
│   ├── mining_controller.h         # 采矿逻辑（挂机）
│   ├── market_controller.h         # 集市交易逻辑
│   └── quest_controller.h          # 任务系统逻辑
│
├── view/                           # View - 显示层
│   ├── terminal_view.h             # 终端界面渲染
│   └── input_parser.h              # 输入解析
│
├── data/                           # 静态数据定义
│   ├── items.h                     # 物品数据
│   ├── crops.h                     # 作物数据（5 种）
│   ├── fish.h                      # 鱼类数据（5 种）
│   ├── ores.h                      # 矿石数据（5 种，含各矿区概率）
│   └── events.h                    # 事件数据
│
└── util/
    ├── serializer.h                # JSON 序列化（持久化）
    └── random.h                    # 随机数工具
```
