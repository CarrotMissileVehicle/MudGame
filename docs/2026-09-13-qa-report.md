## 2. 缺陷明细与闭环证据

### DEF-101（P1）cmdparser · ParameterCollector 死循环
- **现象**：必填参数输入为空（管道/文件输入耗尽）时无限重提示；测试 `RequiredMissingReturnsFalse` 挂起约 150 秒后 `std::bad_alloc`（缓冲无限增长）。
- **根因**：`collect()` 中必填且空输入时 `continue` 重提示，输入源耗尽即死循环。
- **修复**：改为打印提示后 `return false` 取消本次收集（`src/View/Cmdparser/src/parameter_collector.cpp`）。
- **验证**：`cmdparser_interactive_test` 5/5 通过，0ms。
- **提交**：`17c185d`。

### DEF-102（P1）main · time.scale 非法参数崩溃
- **现象**：`time.scale abc` → `std::stod` 抛 `invalid_argument` 未捕获，FTXUI 主循环 terminate。
- **修复**：try/catch 拦截，提示后返回 `HandlerResult::BadArgument`；显示改用钳制后的实际倍率（`main.cpp`）。
- **验证**：整项目构建通过 + 人工审查（REPL 处理器无单测锚点，按计划以构建+审查验证）。

### DEF-103（P2）timeservice · 倍率无边界 + double→int UB
- **现象**：`set_time_scale(1e18)` 后 `update()` 内 `static_cast<int>(floor(sub_minute_/60.0))` 为 UB（实测负值 → 提前 return，`sub_minute_` 状态被污染）；NaN/负值语义含糊。
- **修复**：`set_time_scale` 钳制到 `[0, 1e6]`，负值/NaN 一律视为 0（静止）。上限 1e6 = 单帧 floor(1e6/60)=16666 分钟，可控且无转换 UB（`time_service.cpp` + 头文件契约注释）。
- **验证**：新增 TS-SC-011/012/013（`tests/timeservice/time_scale/bound_test.cpp`）；`timeservice_scale_test` 12/12；timeservice 全模块 8/8。

### DEF-104（P2）player_serializer · 损坏存档解析崩溃
- **现象**：`satiety=abc`（invalid_argument）、`gold=999…9`（out_of_range）等损坏字段令 `Load` 抛异常逃逸 → 读档崩溃。存档属不可信输入。
- **修复**：新增 `to_int_or`/`to_ll_or` 安全解析助手（损坏回退默认值）；金币/总分钟数行损坏时视为该段缺失，保持调用方初值（`PlayerSerializer.cpp`）。
- **验证**：`player_serializer_robustness_test` 3/3（数值损坏回退、非法日历不崩、物品行损坏回退）。

### DEF-105（P2）player_serializer · 非法日历字段 chrono UB
- **现象**：`saveOpenMonth=0`、`saveOpenDay=32`、2月30 等 → `sys_days{ymd}` 对非法 `year_month_day` 为 UB。
- **修复**：以 `ymd.ok()` 拦截，非法时保持 game 既有存档时间（与 1970 前分支同语义）；年份钳制 [0,9999] 防窄化转换，时/分钳制 [0,23]/[0,59]（`PlayerSerializer.cpp`）。
- **验证**：`InvalidCalendarKeepsDefaultNoCrash` 通过；往返 3/3 保持绿（合法存档行为不变）。

### DEF-106（P2）main · market.sell 售价 0 仍移除物品
- **现象**：浮动令售价截断为 0 时 `sell()` 返回 0，但处理器无条件 `RemoveObject` → 物品白送消失。
- **修复**：`gained <= 0` 时提示「售价为 0」并返回 Failed，不移除物品；同时将 `gained` 收窄 int 修正为 long long（`main.cpp`）。
- **验证**：Market 层语义锚点 `SellZeroPriceAddsNothing` + 构建通过。
- **语义锚点**：`tests/market/trade/market_trade_test.cpp`。

### DEF-107（P3）market · 浮动有放回抽取重复
- **现象**：`updateFluctuations()` 有放回抽取，同日可重复命中同一商品 → map 覆盖，实际品种缩水、返回值虚报（设计为每天 2-3 种不同商品）。
- **修复**：部分洗牌（Fisher-Yates 前缀）实现不放回抽取（`Market.cpp`）。
- **验证**：`ClaimedCountEqualsDistinctItems` 50 天滚动断言返回值 == 实际浮动品种数（修复前必红，重复概率约 1e-13 才漏检）。

### DEF-108（P3）farming_controller · 越界索引崩溃
- **现象**：`farm.plant 99` 等用户输入直达 `Farm::getFarmland().at()` 抛 `out_of_range` 未捕获 → 崩溃。
- **修复**：`sow/water/fertilize/harvest` 入口统一 `in_bounds` 守卫（nullptr + 索界），越界以 false/0 拒绝（`FarmingController.cpp`）。
- **验证**：`farming_bounds_test` 5/5（四操作越界拒绝 + 合法路径不误伤）；farm 模块 15/15。

### DEF-109（P4）main · market.buy 提示金额溢出
- **现象**：`price * count` 提示金额在大金币/大数量下回绕显示错误。
- **修复**：64 位计算 `spent` 后显示（`main.cpp`）。
- **验证**：构建 + 审查（显示路径）。

### DEF-110（P4）· 只记录不修（按计划）
- 天气 neglect 天数首日 +1 偏差；读档后集市/天气日历不同步；工具 restore 等级未额外钳制（ToolController::restore 内部已有夹取，风险低）。
