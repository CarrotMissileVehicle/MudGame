# timer_queue —— 定时器队列与延时任务测试

覆盖一次性/周期定时调度：到期触发精度、同帧多回调顺序、周期续排、`schedule` 期间回调内再注册、
到期在历史时刻的边界，以及由此导致的**事件丢失 / 周期漂移**等风险。

## 前置条件
- 被测：`mud::TimeService`；定时器入口 `schedule_time(due, cb)`、`schedule_interval(minutes, cb)`。
- 动作口径：回调触发判定窗口为 `(before, after]`（before=推进前时刻，after=推进后时刻）。

## 判定口径
- 周期漂移（R4 / TS-TQ-007）：当前算法「每周期续排 1 次、跳过跨期」，若产品期望「补偿所有
  错过的周期」则当前实现不满足——用例登记为该语义的回归哨兵，明确事中语义、不静默吞吞吐。
- 事件丢失（R3 / TS-TQ-013）：大跳变下窗口外回调不触发属当前实现限制，用例验证其**可观测、
  不崩溃**，并在有补发机制后回归。

## 执行前准备
- 用旁路记录向量断言触发序列；用队列快照断言移除/续排。
- 误差：当前帧驱动以「目标帧」为验收；仅在接入真实时钟的扩展形态下启用「≤50ms」阈值。
