# calendar_event —— 日历进位、昼夜与季节、全局事件测试

覆盖日期字段进位正确性（月界/年界/闰年）与昼夜（06:00 日出 / 18:00 日落）、季节更迭及
全局事件触发的**目标形态**测试。当前 `TimeService` **尚未实现**昼夜/季节事件系统，
日历进位部分直接可测，事件部分标记为扩展。

## 前置条件
- 日历被测：`mud::time::GameDateTime`（`total_minutes()` / `advance()`）。
- 服务被测：`mud::TimeService`（`set_time()` / `update()`）。
- 目标事件系统（06:00 日出、18:00 日落、季节更迭点）**当前为需求目标，实现前按扩展用例执行**。

## 判定口径
- **日历部分**：以系统 `<chrono>` 日历能力为参照，`GameDateTime` 进位必须与其一致（含闰年、月天数）。
- **事件部分**（TS-CE-008~012）：当前模块未实现事件系统，执行前需先确认是否有对应实现；
  若缺失则标记 **NOT-IMPLEMENTED**（不判失败，登记为待实现），实现后回归执行。

## 观测方式
- 日历：交叉断言 `total_minutes()` 与独立 `std::chrono` 换算。
- 事件：事件总线/回调旁路记录触发时刻与序列；校验「至多一次、边界不早不晚、顺序确定性」。
