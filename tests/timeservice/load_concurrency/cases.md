# load_concurrency —— 高并发 / 负载 / 瞬时洪峰测试

验证定时器队列在高并发、大批量注册/取消、单帧到期洪峰等压力下的稳定性、性能与内存无泄漏。

## 前置条件
- 被测：`mud::TimeService` 单实例（时间模块上层为单线程游戏循环，主路径线性，但需验证回调顺序与稳定性）。
- 压力注入：批量 `schedule_time` / `schedule_interval`，制造单帧多到期洪峰与持续高频推进。

## 判定口径
- 性能阈值：本方案给 **注册/单帧洪峰处理 < 100ms**（TBD 依据目标机），执行时可调。
- 内存：取消/到期后队列条目数回落、无线性增长；峰值=同时挂起条数即通过。
- 回调顺序在洪峰下仍须稳定（复现依赖排序判据，见 `timer_queue` TS-TQ-005）。

## 执行前准备
- 用可观测的队列快照接口（或行为断言）采集峰值/回落；埋点记录各操作耗时。
- 真并发（TS-LC-009）：当前为单线程游戏循环，默认跳过并标注；引入多线程时启用。
