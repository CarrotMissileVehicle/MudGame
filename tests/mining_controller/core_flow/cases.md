# 采矿核心流程测试（core_flow）

> 关注：采矿读条、`BUSY` 锁定、状态机跃迁与产出结算的**主链路**正确性。
> 判定基准：状态守恒 + 副作用守恒；见 `../README.md`。
> 代码现状：`start / poll / update / stop` 状态机与 interval 轮询已实现；**中断/移动锁定、离线结算、BUFF 触发**为目标形态。

## MIN-CF 用例清单

### MIN-CF-001 空闲态启动采矿（Idle → Mining）
- **前置**：空闲、等级/照明/工具/储量校验通过。
- **输入**：`mine.start --layer <合法层>`。
- **预期**：返回 `true`；状态进入 `Mining`；`layer_id`/`start_time`/`last_tick` 正确写入。
- **验证重点**：合法跃迁且会话字段初始化完整（含计时点）。

### MIN-CF-002 采矿中重复启动（硬直拦截）
- **前置**：已在采矿（BUSY）。
- **输入**：`mine.start --layer <另一层>`。
- **预期**：返回 `false`，提示「已在采矿中/动作冷却」；不覆盖当前 `layer_id`、不重置计时点；控制器不二次 `start`。
- **验证重点**：BUSY 状态下拒绝重新进入，会话数据不被破坏。

### MIN-CF-003 采矿中发起移动 / 攻击 / 交互
- **前置**：采矿中。
- **输入**：`go north`、攻击、使用交互命令。
- **预期**：按设计拦截（提示「采矿中无法行动」）或进入延迟队列；**不得**中断/覆盖采矿会话。
- **验证重点**：BUSY 锁定对移动/攻击/交互的拦截语义与会话完整性（当前命令层未实现，按设计验收）。

### MIN-CF-004 读条到期的单次产出结算
- **前置**：`start` 后经过恰好一个 `interval`（工具默认「核心镐」`interval=1` 游戏分钟，可注入更快档位）。
- **输入**：推进 `time_service` 至 `start_time + interval`，执行一次 `poll`。
- **预期**：返回恰好一份 `MiningResult`（`ore_id`/`experience`/`quantity`）；`last_tick` 更新；状态仍为 `Mining`。
- **验证重点**：interval 到期判定精确到游戏分钟，产出数量与到期间隔数匹配。

### MIN-CF-005 未到下一次 interval 不产出
- **前置**：刚完成一次 `poll` 不足一个 interval。
- **输入**：再次 `poll`。
- **预期**：返回**空**产出；`last_tick` 不推进到超界值；状态不变。
- **验证重点**：未到期不产出、不漏产出、不重复产出。

### MIN-CF-006 跨多个 interval 一次结算多份产出
- **前置**：采矿持续 N 个 interval 未 poll。
- **输入**：一次性 `poll`。
- **预期**：返回 N 份产出（每 interval 一份）；`last_tick` 前移对应 N；储量/耐久 各扣 N。
- **验证重点**：补捞本应到期的产出，计数正确（不丢、不多）。

### MIN-CF-007 采矿中停止（Mining → Idle 结算）
- **前置**：采矿中已积累未提取产出。
- **输入**：`mine.stop`。
- **预期**：返回并结算未提取产出；状态复位 `Idle`；`layer_id` 清空；停止后不可再产。
- **验证重点**：`stop` 结算完整、状态机复位为可再入（无残留脏状态）。

### MIN-CF-008 停止后恢复再采矿
- **前置**：`stop` 后回到 Idle。
- **输入**：`mine.stop` → `mine.start --layer <层>`。
- **预期**：再次 `start` 成功进入新会话，计时点重新初始化。
- **验证重点**：Idle 可再入，旧会话数据不复用。

### MIN-CF-009 `mine.status`/`layer`/`start_time` 只读查询
- **前置**：空闲态与采矿中各查一次。
- **输入**：`mine.status`、`layer_id()`、`start_time()`。
- **预期**：仅返回当前状态/层/时间，**不**改变状态、不结算产出。
- **验证重点**：查询命令无副作用。

### MIN-CF-010 采矿完成为空矿脉后强制结束
- **前置**：采矿中且矿脉储量已归 0。
- **输入**：`poll`。
- **预期**：产出数截断至剩余储量；储量 0 后会话自动结束/提示「矿脉已采空」；无负产出。
- **验证重点**：储量耗尽时产出与储量守恒，会话终态明确。

### MIN-CF-011 中途取消采矿（玩家主动 quit / 取消）
- **前置**：采矿中。
- **输入**：`mine.cancel` / `quit`。
- **预期**：明确并一致：结转已到期产出或明示丢弃；会话复位 Idle；不产生异常回滚。
- **验证重点**：取消语义契约固定（不丢未结算产出、不回滚异常）。

### MIN-CF-012 切换地图 / 离开矿洞
- **前置**：采矿中切换地图。
- **输入**：离开当前矿区。
- **预期**：按设计中断采矿（结算当期产出）或将产出结转；不得残留飞行中的会话状态。
- **验证重点**：跨场景会话生命周期与产出归属。
