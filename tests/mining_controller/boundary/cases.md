# 边界与异常场景测试（boundary）

> 关注：无工具、工具损坏、矿脉已空、玩家离线、取消采矿、切换地图、重复点击、外挂高频请求等边界/异常条件。
> 判定基准：状态守恒 + 异常兜底——任何输入不导致崩溃/未捕获异常/误结算；见 `../README.md`。

## MIN-BD 用例清单

### MIN-BD-001 外挂高频请求（速率限制）
- **前置**：单玩家以极高频（如 1000 req/s）连发采矿/轮询。
- **输入**：连发 `mine.start` / `poll`。
- **预期**：服务按速率限制/节流拒掉超频部分；无崩溃、无重复结算、无账目错乱。
- **验证重点**：速率限制与请求去重，防脚本刷产出。

### MIN-BD-002 重复点击 `start`/`poll`（双击竞态）
- **前置**：同一帧/同一 tick 多个相同指令。
- **输入**：并发 `start` 与 `poll`。
- **预期**：幂等处理——只生效一次；状态不因重复点击错乱。
- **验证重点**：双击/帧竞态下的幂等性（呼应 CC-005）。

### MIN-BD-003 越界层号 / 非法层
- **前置**：`layer_id` 超过层表范围（如 5 / 999）。
- **输入**：`mine.start --layer 99`。
- **预期**：被拒且返回 `false`；不进入采矿；无产出（已实现：`can_enter_layer` 越界拦截）。
- **验证重点**：层索引边界。

### MIN-BD-004 采矿中切换地图 / 离开矿洞（再次覆盖）
- **前置**：采矿中。
- **输入**：离开当前矿区。
- **预期**：中断会话并结算当期产出或将产出结转；不残留飞行会话。
- **验证重点**：跨场景会话生命周期（与 CF-012 呼应）。

### MIN-BD-005 取消采矿后清账
- **前置**：采矿中。
- **输入**：`mine.cancel` / 主动 quit。
- **预期**：结转已到期产出或明示丢弃；状态复位；无资源泄漏（计时点、会话引用释放）。
- **验证重点**：取消路径的资源清理与账目一致。

### MIN-BD-006 矿脉已空后的一切请求
- **前置**：`reserve=0`。
- **输入**：`start`、`poll`。
- **预期**：全部拒绝；提示采空；无负产出、无异常崩溃。
- **验证重点**：耗尽态访问的无异常兜底。

### MIN-BD-007 工具损坏 / 无工具下的轮询
- **前置**：`durability=0` 或无工具。
- **输入**：`poll`。
- **预期**：无产出、提示工具损坏/缺失；会话不产生副作用；不崩溃。
- **验证重点**：异常工具态的无副作用轮询。

### MIN-BD-008 玩家离线 / 会话注销
- **前置**：玩家登出。
- **输入**：登出期间到达的采矿或轮询。
- **预期**：产出归属明确（落袋或待领），不凭空丢失；服务器不因空玩家崩溃。
- **验证重点**：离线边界的一致性（呼应 PR-008）。

### MIN-BD-009 非法输入与畸形指令（注入/超长/Emoji/特殊字符）
- **前置**：任意畸形输入。
- **输入**：超长层号、非数字参数、特殊字符、Emoji、注入串。
- **预期**：解析/前置层安全拒绝；不崩溃、不未捕获异常、不误进入采矿。
- **验证重点**：异常兜底的输入健壮性（与 cmdparser 跨模块联动）。

### MIN-BD-010 睡眠态 / 夜间 / 异常内心态下的采矿
- **前置**：玩家处于睡眠或日夜/气候限制层（若时间模块联动）。
- **输入**：`mine.start`。
- **预期**：按时间/状态联动拦截或放行；被拦截时无副作用。
- **验证重点**：采矿与时间/玩家状态系统的边界联动一致性。
