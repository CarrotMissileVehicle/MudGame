# 语义级测试用例（semantic）

> 关注：语法已通过的参数值是否被正确解释、校验范围与资源/指令语义匹配。
> 判定基准：见 `../README.md`「通用通过 / 失败判定标准」。

## CP-M 用例清单

### CP-M-001 合法层号解析
- **场景**：`--layer` 取值在合法范围内。
- **输入**：`mine.start --layer 0` / `--layer 4`（下/上边界）
- **预期**：接受；`target_layer` 正确；在等级与资源校验通过后进入采矿。
- **验证重点**：合法层解析为层索引，成功进入业务。

### CP-M-002 层号越界（高）
- **输入**：`mine.start --layer 5`
- **预期**：拒绝 `--layer 5`（超出 `shallow..core` 0-4 范围）→ 返回 `BadArgument` 或 `verb="error"`；**不启动采矿**。
- **验证重点**：越界层不进入后端、有明确用户提示。

### CP-M-003 层号越界（负）
- **输入**：`mine.start --layer -1`
- **预期**：负数被拒绝（无合法负层）→ `BadArgument`；不启动采矿，不崩溃。
- **验证重点**：负值边界处理。

### CP-M-004 层号非数字
- **输入**：`mine.start --layer abc`、`mine.start --layer 1.5`、`mine.start --layer " 3"`
- **预期**：非整数/带空白/小数形式被拒绝或安全归一；不产生越界/非法下标访问；返回明确错误。
- **验证重点**：类型强校验，杜绝 `std::size_t` 隐式非法转换导致未定义行为。

### CP-M-005 矿石资源不存在
- **场景**：请求的矿石不在 `ore.json`。
- **输入**：`mine diamond`（无 `ore_diamond`）、目标形态 `mine copper`（取决于数据中是否有 copper）
- **预期**：在资源映射阶段拦截，提示“目标资源不存在”；**不启动采矿、不调用产量计算**。
- **验证重点**：资源存在性校验在语义/逻辑层生效，杜绝查不到数据的空产出。

### CP-M-006 矿石—矿层一致性
- **场景**：请求矿层与矿石所在层匹配。
- **前置**：基于 `Data/Ore/*.json` 快照；`ore_iron` 位于浅层、`ore_core` 位于核心层。
- **输入**：在`核心层`请求 `ore_iron`；在`浅层`请求 `ore_core`
- **预期**：层与矿石不匹配时被拦截；匹配时才结算该矿石。
- **验证重点**：层—矿石映射的数据一致性校验。

### CP-M-007 `--factor` 缺失
- **输入**：`time.scale`
- **预期**：必填项缺失 → `verb="error"` / `BadArgument`；不修改时间倍率。
- **验证重点**：`required()` 缺失语义层拒绝。

### CP-M-008 `--factor` 类型与范围
- **输入**：`time.scale --factor abc`、`time.scale --factor -2`、`time.scale --factor 0`、`time.scale --factor 1000`
- **预期**：非数值被拒；负/零/极端倍率按系统约定被拒绝或钳制，进入 `set_time_scale` 前有边界守卫。
- **验证重点**：时间倍率的类型与上下界守卫。

### CP-M-009 无参子命令不带参数
- **场景**：无参数子命令误带参数。
- **输入**：`mine.stop extra`、`mine.status 1 2`
- **预期**：多余位置参数被忽略、拒绝或归入 `args`（按 CLI 约定），命令本身仍按定义执行/拒绝；不误把多余词当必填项。
- **验证重点**：`remaining` 位置参数的去留与对现有命令的影响。

### CP-M-010 跨 schema 的互斥选项
- **场景**：不属于该子命令的命名参数。
- **输入**：`mine.start --layer 1 --factor 2`、`time.now --layer 3`
- **预期**：`mine.start` 不接受 `factor`、`time.now` 不接受 `layer` → 拒绝返回 `verb="error"`；不静默忽略产生歧义。
- **验证重点**：选项与子命令的归属关系强约束。

### CP-M-011 层号前导补位/长数字
- **输入**：`mine.start --layer 0001`、`mine.start --layer 2147483648`
- **预期**：前导零解析为 `1`（若 CLI 支持）；超 `int` 上限值被安全拒绝或归一，不溢出、不越界。
- **验证重点**：数值解析的溢出安全与归一规则。

### CP-M-012 缺省层语义（`mine` 形态）
- **场景**：目标形态 `mine`（无层号）。
- **输入**：`mine`
- **预期**：被要求提供层号/矿石目标 → `BadArgument` 并提示“请指定矿层或矿石”；不启动采矿。
- **验证重点**：缺省必参的语义拦截与用户引导提示。
